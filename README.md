# TEN Cybersecurity Internship - Task 1: Nmap Scan

## Objective
To perform network reconnaissance and service version detection on a target server using Nmap to identify active ports, protocols, and running software versions.

## Command Executed
`nmap -sV -oN nmap_report.txt scanme.nmap.org`

## Scan Analysis & Key Findings
* **Target Host:** scanme.nmap.org (45.33.32.156)
* **Scan Time:** 22.23 seconds
* **Discovered Ports:**
  * **Port 22 (SSH):** Open - Running OpenSSH 6.6.1p1 (Ubuntu Linux). Used for secure remote management.
  * **Port 80 (HTTP):** Open - Running Apache httpd 2.4.7. Standard public web server port.
  * **Port 9929 (nping-echo):** Open - Running Nping echo service.
  * **Port 31337 (tcpwrapped):** Open - Standard Nmap testing port.
* **Firewall Status:** Ports 135, 139, and 445 are properly listed as `filtered`, meaning a firewall is actively protecting those common Windows network channels.
